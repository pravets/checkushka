# RoleWithoutRights — роль без прав

**Важность:** MINOR · **Тип:** CODE_SMELL · **Теги:** STANDARD, DESIGN · **Уровень:** роль

## Что проверяет

Роль, у которой не установлено ни одного права: список прав пуст либо все права выключены.
Такая роль бесполезна и обычно остаётся после рефакторинга или копирования.

Проверка читает данные роли через mdclasses (`RoleData.objectRights`), поэтому работает и для
выгрузки конфигуратора, и для проекта EDT.

## Пример настройки

```json
{
  "checks": {
    "severity": {
      "RoleWithoutRights": "MAJOR"
    }
  }
}
```

## Исключение

Если роль поставляет вендор и трогать её нельзя:

```json
{
  "ignore": [
    { "check": "RoleWithoutRights", "mdo": "Role.ОбновлениеИБ", "reason": "роль поставщика" }
  ]
}
```

# FormWithoutTitle — форма без заголовка

**Важность:** MINOR · **Тип:** CODE_SMELL · **Теги:** STANDARD, DESIGN · **Уровень:** форма

## Что проверяет

Форму, у которой не заполнен заголовок (`FormData.title` пуст). Проверяются общие формы и
формы объектов.

Правило фиксирует пустое значение и не утверждает, что заголовок обязателен всегда: часть форм
получает заголовок автоматически. Если для проекта это норма, проверку отключают.

## Пример отключения

```json
{
  "checks": {
    "parameters": {
      "FormWithoutTitle": false
    }
  }
}
```

или через исключение по объекту:

```json
{
  "ignore": [
    { "check": "FormWithoutTitle", "mdo": "Catalog.Товары", "reason": "заголовок задаётся в модуле" }
  ]
}
```

## Где ищется файл формы

- Designer: `<Объект>/Forms/<Имя>.xml`;
- EDT: `<Объект>/Forms/<Имя>/Form.form`.
